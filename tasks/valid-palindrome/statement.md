# Палиндром

Строка — палиндром, если после перевода всех букв в нижний регистр и удаления всего, кроме латинских букв и цифр, она читается одинаково в обе стороны. Верни `true`, если `s` палиндром.

Пример: `"A man, a plan, a canal: Panama"` → `true`; `"race a car"` → `false`; `" "` → `true`.

Строка состоит из печатных ASCII-символов. Попробуй без выделения новой строки.

Оригинал: https://leetcode.com/problems/valid-palindrome/
