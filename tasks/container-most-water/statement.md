# Контейнер с водой

Дан массив `height`: в точке `i` стоит вертикальная стенка высоты `height[i]`. Выбери две стенки так, чтобы вместе с осью X они образовали контейнер с максимальным объёмом воды, и верни этот объём: `(j - i) * min(height[i], height[j])`.

Пример: `[1,8,6,2,5,4,8,3,7]` → `49`.

Ограничения: 2 ≤ n ≤ 10^5, решение за O(n²) не пройдёт.

Оригинал: https://leetcode.com/problems/container-with-most-water/
