# K самых частых

Дан массив `nums` и число `k`. Верни `k` самых частых элементов в любом порядке. Ответ гарантированно единственный.

Пример: `[1,1,1,2,2,3]`, `k = 2` → `[1,2]`.

Подумай, как обойтись без сортировки всех частот: есть решение за O(n).

Оригинал: https://leetcode.com/problems/top-k-frequent-elements/
