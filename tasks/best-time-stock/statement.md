# Лучший момент для сделки

`prices[i]` — цена акции в день `i`. Можно один раз купить и позже один раз продать. Верни максимальную прибыль или `0`, если заработать нельзя.

Пример: `[7,1,5,3,6,4]` → `5` (купить за 1, продать за 6); `[7,6,4,3,1]` → `0`.

Оригинал: https://leetcode.com/problems/best-time-to-buy-and-sell-stock/
