# Самая длинная последовательность

Дан неотсортированный массив `nums`. Верни длину самой длинной последовательности подряд идущих целых чисел (элементы могут стоять в массиве где угодно).

Пример: `[100,4,200,1,3,2]` → `4` (это 1, 2, 3, 4).

Цель — O(n) без сортировки. Пустой массив → `0`.

Оригинал: https://leetcode.com/problems/longest-consecutive-sequence/
