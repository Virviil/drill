# Произведение кроме себя

Дан массив `nums`. Верни массив `answer`, где `answer[i]` — произведение всех элементов `nums`, кроме `nums[i]`.

Деление использовать нельзя, сложность O(n). Все произведения помещаются в int.

Пример: `[1,2,3,4]` → `[24,12,8,6]`; `[-1,1,0,-3,3]` → `[0,0,9,0,0]`.

Оригинал: https://leetcode.com/problems/product-of-array-except-self/
