# Подстрока без повторов

Дана строка `s` (ASCII). Верни длину самой длинной подстроки, в которой нет повторяющихся символов.

Пример: `"abcabcbb"` → `3` (`"abc"`); `"bbbbb"` → `1`; `"pwwkew"` → `3` (`"wke"`; `"pwke"` — не подстрока).

Ограничения: 0 ≤ len(s) ≤ 10^5.

Оригинал: https://leetcode.com/problems/longest-substring-without-repeating-characters/
