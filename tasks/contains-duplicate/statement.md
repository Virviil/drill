# Есть ли дубликат

Дан массив целых чисел `nums`. Верни `true`, если какое-то значение встречается в нём хотя бы дважды, и `false`, если все элементы различны.

Пример: `[1,2,3,1]` → `true`; `[1,2,3,4]` → `false`.

Ограничения: 1 ≤ len(nums) ≤ 10^5, −10^9 ≤ nums[i] ≤ 10^9.

Оригинал: https://leetcode.com/problems/contains-duplicate/
